# pairwise-lighting

## 题面（可直接粘贴）

点光源衰减与多光源能量守恒叠加。约束：距离 0 取 1、半径外取 0、区间内单调递减且一阶连续（soft radius）；多光源叠加必须按总能量归一，不得因光源数量增加而整体过曝；10 万次衰减不超过 250 ms；同一光源并发求值安全；非法半径、非有限坐标、空光源列表要给出可区分的错误；不得修改输入光源。验收：python -m pytest tests -q -k light。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 非有限坐标
- 10 万次耗时
- 并发
- 半径边界
- 多光源排序

## 运行方式

```bash
python -m pytest tests -q
```
